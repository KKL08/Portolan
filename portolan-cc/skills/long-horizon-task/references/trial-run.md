# 初始化与试跑

> 定位：portolan skill 的 reference。确认协议落盘后、正式分发前的环节。

## 初始化

任务目录（`.portolan/<slug>/`）在确认协议落盘时已建好，三份文件（任务协议单、工作底稿、批注区）已就位。本环节补齐执行侧文件：

1. 按 `templates/execution.md` 实例化 execution.md 到任务目录（占位符填实规则见 `references/dispatch.md` 步骤 1，此时用确认协议值，试跑后更新）
2. 按 `templates/journal.md` 在任务目录建 journal.md 骨架——保留页眉写者注与终态声明节的字段骨架（终态/依据/复核方式/下一步建议），执行环照骨架填（它读不到 skill 模板路径）
3. 工作底稿状态从"准备中"改为"执行中"

**先组装后试跑**——试跑用的是真产物的小装药版（小数据量、单个子题、样本行），不是另做一套。

## 试跑决策卡

组装完成后，根据快速通道判定结果分流：

**快速通道任务**（基础摸底评估阶段已判定）：机械免试跑，不出卡，底稿试跑规模写"快速通道，免试跑"。直接读 `references/dispatch.md` 进入分发。

**非快速通道任务**，出决策卡：

```
【决策卡】要不要先试跑？
要决什么：正式发射前是否先点火。
为什么现在问：执行产物已组装完成，试跑预计 {{预估耗时}}。
推荐 A（理由：{{本任务为什么建议试跑，如含软 eval / 单轮成本高}}）
A. 先试跑：三必测跑一遍，绿灯再发射
B. 跳过试跑直接发射：任务协议单决议记录将记一行"用户选择跳过试跑，风险自担 + 日期"
回复 A 或 B。
```

用户选 B：**必须先在任务协议单决议记录写一行"用户选择跳过试跑，风险自担 + {{日期}}"，重算任务协议单冻结哈希更新进底稿起点事实表，再读 `references/dispatch.md` 进入分发。** 不许静默跳过。

用户选 A 或默认推荐：进入点火。

## 点火：三必测两按需

试跑由发起 agent 亲手跑，不经 `/goal`（斜杠命令是用户层的，agent 发不了）。

### 三必测

1. **链路通不通**——任务的第一条命令真跑一次，确认工具链、权限、路径都通
2. **裁判判不判得动**——硬 eval 和软 eval 都要测：
   - 硬 eval：亲手跑一次，确认断言能跑、能判对也能判错
   - 软 eval：用试跑小装药产出 + 一份故意做坏的对照样本，派一次评审 subagent 按 rubric.md 判，确认能判对也能判错
   - 只有人工点没有硬/软 eval 的任务，此项跳过
3. **证据写不写得出**——journal 试写一条到底稿试跑复盘节（不写进正式 journal），确认格式和证据指针能落地

### 两按需

4. **协作顺不顺**——有人工配合环节才测：模拟到人工点停下来、等批准、拿到批准继续的流程
5. **迭代收不收敛**——迭代型任务才测：跑两轮，看第二轮是否在第一轮基础上有可测进展
6. **重复稳健性**——"次次都成"档位才测：换一组边界输入（空源、超时、格式异常）再跑一遍

### 不可逆环节处理

不可逆环节用替身：dry-run 模式、沙箱环境、假收件人。**真动作不在试跑发生。** 找不到无副作用替身的环节（如对外提 PR），试跑只验证到动作前一步，复盘记"该环节未点火"（详见 dispatch.md"不可逆环节替身补充"）。

## 复盘与校准

复盘用直接观察数据，不用 agent 自述：

- 输出是否符合预期
- 有没有报错或重试
- 耗时多少
- eval 是否正常判定（包括该判错时能不能判错）

复盘结果（三必测/按需项结论、journal 试写样条、未点火环节）记进工作底稿试跑复盘节，并按实测校准底稿运行参数：
- **熔断值**——实测暴露的合理阈值，更新进底稿
- **轮次上限 N**——按单轮耗时和总预算推算，更新进底稿
- **成本预估**——按实测单轮消耗外推，更新进底稿
- **试跑规模**——实际用的小装药描述，更新进底稿

### 绿灯

三必测全过 → 读 `references/dispatch.md` 进入分发。

### 失败

任一必测不过 → 回修。修完记底稿修订记录，重跑失败项。**试跑失败是发起会话内唯一回头修协议的入口**（停点后另有 continue/finish 的修订通道）——如果问题出在成功标准或 eval 设计本身，允许修订任务协议单，走协议修订流程（等同初次确认分量的确认）。
